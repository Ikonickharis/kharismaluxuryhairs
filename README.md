## 🌐 Pages Overview

### 1. `index.html` (Home)
- Features a hero section with a transparent background image and a call-to-action button.
- Introduces visitors to the brand with elegant styling and layout.

### 2. `about.html`
- Presents the company’s story, mission, vision, and core values.
- Includes a mix of imagery and text for brand storytelling.

### 3. `services.html`
- Highlights the range of luxury hair services offered:
  - Hair installation
  - Custom wig making
  - Hair treatments
  - Coloring & styling

### 4. `gallery.html`
- Features a responsive **carousel slider** showcasing real product styles and clients.
- Navigation arrows allow users to browse through multiple hair images.

### 5. `contact.html`
- Includes a responsive contact form with client-side validation.
- Contact details (email, phone, and location) are provided.

## 🎨 Features

- ✅ Fully responsive design (mobile-friendly)
- ✅ Sticky header and footer
- ✅ Responsive navigation menu with toggle on mobile
- ✅ JavaScript-powered contact form with validation
- ✅ Custom-built image carousel in the gallery
- ✅ Clean and modern UI using semantic HTML5 and CSS3
